## rc583 2026-10-11
[en]
- Multiplayer mode: View > Target game > Multiplayer. The notes then also show what does nothing or works differently on an MP server – camera, print without !, fields MP doesn't know or only stubs, fields that only work on NPCs or players, server crash risks (SET_WEAPON, SET_COPY_ORIGIN, SET_SABERACTIVE), the reversed SET_SABERACTIVE, $get that never returns a value, dowait that never returns, more than 32 variables. Every rule was checked against the MP game code. Thanks to @Seph for the report.
- A misspelled SET_ field in set ( ... ) is now reported with a suggestion (e.g. SET_ORIGNI – did you mean SET_ORIGIN?).
- The original font: BehavEd 2002 uses MS Sans Serif 8 pt everywhere; BehavEd-Remake now uses its TrueType version (Microsoft Sans Serif). Minus signs and dots are easier to see.
- The event editor fits into the window: commands with many fields (e.g. camera PAN) no longer stick out of the window – fields give up their spare width first.
- Compile refuses a script with a line it doesn't understand (e.g. a missing parenthesis) or a block without a closing }, like the original IBIze. Before, such a line was silently left out of the .ibi.
- Opening a script lists every line that wasn't understood in the status bar, with its line number.
- Changelog window (File menu, About window, update window) – in every language.
- Command line: bhed compile no longer writes an .ibi when compiling fails.
[de]
- Multiplayer-Modus: Ansicht > Zielspiel > Multiplayer. Die Anmerkungen zeigen dann zusätzlich, was auf einem MP-Server nichts tut oder anders geht – camera, print ohne !, Felder, die der MP nicht kennt oder nur als Stub hat, Felder nur für NPCs oder Spieler, Absturzgefahr für den Server (SET_WEAPON, SET_COPY_ORIGIN, SET_SABERACTIVE), das umgekehrte SET_SABERACTIVE, $get ohne Wert, dowait ohne Rückkehr, mehr als 32 Variablen. Jede Regel ist am MP-Spielcode geprüft. Danke an @Seph für den Bericht.
- Ein vertipptes SET_-Feld in set ( ... ) wird jetzt mit Vorschlag gemeldet (z. B. SET_ORIGNI – meintest du SET_ORIGIN?).
- Die Schrift des Originals: BehavEd 2002 nutzt überall MS Sans Serif 8 pt; BehavEd-Remake nimmt jetzt deren TrueType-Fassung (Microsoft Sans Serif). Minus und Punkt sind besser zu erkennen.
- Der Ereigniseditor passt ins Fenster: Befehle mit vielen Feldern (z. B. camera PAN) ragen nicht mehr hinaus – zuerst geben die Felder ihren freien Platz ab.
- Übersetzen verweigert ein Skript mit einer unverständlichen Zeile (z. B. fehlende Klammer) oder einem Block ohne schließende }, wie das originale IBIze. Vorher fehlte so eine Zeile still in der .ibi.
- Beim Öffnen nennt die Statusleiste jede nicht verstandene Zeile mit Zeilennummer.
- Changelog-Fenster (Datei-Menü, About-Fenster, Update-Fenster) – in jeder Sprache.
- Kommandozeile: bhed compile schreibt keine .ibi mehr, wenn das Übersetzen scheitert.
[zh]

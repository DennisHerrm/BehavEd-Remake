Tutorials: scripts

Write a script from scratch

A new empty script, an affect block for one figure and a first command inside it.

View:

Steps#

  1. 1

    Open an empty tab. Click the + at the end of the tab bar (or File → New). A new tab unnamed.txt opens with an empty script. The mode bar on the left must be on Events - then the Events list with every command is on the left.

  2. 2

    Find affect in the list. The Events list shows every command of the game with its values. affect is near the top. Hover over it to read what it does.

  3. 3

    Double-click it. affect appears in the script tree in the middle. It is already open (the box in front shows a minus), because a block holds other commands.

  4. 4

    Name the figure. Double-click the new line (or select it and press Enter). The Event editor opens. Type the name of the figure into the first field - with a map loaded, the small arrow next to it lists every name of the map. Leave FLUSH in the second field and press Ok.

  5. 5

    Select the block, then pick the next command. Click the affect line once (1). Then double-click wait in the list (2). Because the selected block is open, the command goes to the start of the block.

  6. 6

    Check the result. wait now sits inside the block, indented under affect. Commands you insert after it follow it, in order, inside the same block.

  7. 7

    Save. Press Save in the action column on the right (or Ctrl+S). The first time, behaved asks for a name - script names are lower case without spaces, for example my_first.txt.

  1. 1

    Switch to Graph. Click Graph above the script area. The graph shows the mission: the player start, the scripts and the entities that start them.

  2. 2

    Drag affect onto free space. Drag affect from the Events list (1) onto an empty spot of the graph (2). A new script is created in the mission folder, with affect as its first command, and opens in its own tab.

  3. 3

    The new node. The new script appears as a node where you dropped it, and it is selected. On the right, Commands of this script shows its one line: affect.

  4. 4

    Name the figure. Double-click the affect line on the right. The Event editor opens - the same as in Classic. Type the name of the figure into the first field and press Ok.

  5. 5

    Add the next command into the block. Click the affect line (1), then double-click wait in the list (2). Because affect is an open block, wait goes inside it.

  6. 6

    Check the result. wait stands indented under affect - it is inside the block. The node counts the commands of the script.

  7. 7

    Save. Save in the action column (or Ctrl+S). The script already has its place in the mission folder.

  1. 1

    Open an empty tab and switch to Tracks. Click + at the end of the tab bar, then Tracks above the script area. The timeline says that nothing is on it yet - and on the right, Command list says *No commands yet*.

  2. 2

    Drag affect into the list. Drag affect from the Events list (1) into the command list on the right (2). An affect block has no time of its own, so it shows in the list, not yet in the timeline.

  3. 3

    Name the figure. Double-click the affect line in the list. The Event editor opens: type the name of the figure into the first field and press Ok.

  4. 4

    Add a walk into the block. Click the affect line (1), then double-click set in the Events list (2) - it goes inside the open block. In the editor choose SET_NAVGOAL and the walk target nav_kyle.

  5. 5

    Now it is on the timeline. The figure got its own row, and the walk is a block on it - as long as the figure needs to get there. Commands without time (affect, the block itself) stay in the list.

  6. 6

    Save. Save in the action column (or Ctrl+S). The first time, behaved asks for a name.

Good to know#

  • With a closed block selected, a new command goes after the block, not into it.
  • Only affect, task, if, else and loop can hold commands.

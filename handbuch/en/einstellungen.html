Settings and updates

Where the program keeps its paths and options, how to change keys, and how updates arrive.

Game folders#

Edit → Game folders lists the folders whose .pk3 archives the program reads, with Up, Down, Remove and Open for each. The bottom one wins over everything above it, as fs_game overrides base in the engine. A folder without archives says so - then the path is wrong.

Preferences#

Edit → Prefs (or Prefs in the action column, Alt+P) holds the options of the original BehavEd:

  • Directories: Script Path, Command Description File (the .bhc that defines every command - Reload command model reads it again), Source Files Path.
  • Re-open last file at startup, Alpha-sort edit pulldowns, Use Alternative Coloured Icons, Yes/No query on Open/New/Exit, File-Open dialog defaults to last dir.
  • Language, theme and interface size are in the View menu.

Changing keys#

Edit → Keyboard shortcuts lists every action that has a key. Click a shortcut and press the new key; Esc cancels, Backspace clears. A key that is already taken is named. The defaults are in Keyboard shortcuts.

Updates and changelog#

Help → Check for updates asks GitHub for a newer version and shows what is new; Download and install replaces the program files and offers a restart. The switch next to it decides whether this happens at startup. Help → Changelog shows what was fixed and added, version by version, in your language - it also opens once by itself after an update.

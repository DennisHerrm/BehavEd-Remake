Commands

set - change a field of an entity

Changes a value of the entity: how it walks, where it goes, what it looks at, its animation, its health ...

View:

What it does#

set with a SET_ field is the most used command of all. Inside an affect block it changes that entity: SET_NAVGOAL makes a figure walk to a walk target, SET_WALKING makes it walk instead of run, SET_LOOK_TARGET turns its head, SET_ANIM_BOTH plays an animation. Every field is in set ( SET_... ) - every field.

Where to enter what#

No.NameWhat it does
1FieldWhich value - a SET_ name from the list. Type part of it to filter.
2ValueThe new value. Its kind depends on the field: true / false, a number, a name from the map, an animation.

Example#

set ( SET_WALKING, true ) and set ( SET_NAVGOAL, "nav_kyle" ) - Kyle walks to nav_kyle.

In Classic, Graph and Tracks#

The switch at the top of the page chooses the view. All three work on the same script - switching loses nothing.

In Classic it is one line of the script tree. Double-click it (or select it and press Enter) to open the editor; right-click for the menu; drag it to move it.

In Graph the script is a node; select it and its commands are listed on the right under Commands of this script. Double-click the line to edit it, right-click for the menu, drop a command from the Events list on it to insert after it.

In Tracks it shows in the row of the figure it belongs to (the name in its affect), as long as it takes. Double-click the block to edit it, right-click for the menu. A walk (SET_NAVGOAL) lasts until the figure arrives; most other fields take no time.

Good to know#

  • A field marked * in its help text (like SET_NAVGOAL) can be waited for with dowait.
  • A value that is not in the list is allowed (mods bring their own) but marked unknown - check it for a typo.

Tutorials

A figure walks

Place a character and a walk target, let the script send it there, then change the path on the map - walk or run, a point in between.

Steps#

  1. 1

    Place a character. In Map mode click the tile Character (NPC_spawner) on the left edge of the view, then click on the floor. In the inspector set NPC_type (the ... button searches every NPC of the game) and a Name such as walker.

  2. 2

    Place a walk target. Click the tile Walk target (waypoint_navgoal) and click where the figure should go.

  3. 3

    Let the script send it. Right-click the character in the entity list → Insert affect block: an affect ( "walker", FLUSH ) block appears. Right-click the walk target in the list → Insert as walk target (SET_NAVGOAL): the line appears below the selected one - drag it into the affect block. The script now reads affect ( "walker", FLUSH ) { set ( SET_NAVGOAL, "..." ); }.

  4. 4

    Play. Press the play button (▶): the figure walks, the path behind it turns yellow. Its row in the timeline shows the walk as a band.

  5. 5

    Run instead of walk. Right-click the end handle of the path → Run (from this walk on). SET_RUNNING is written before the navgoal and the figure arrives sooner.

  6. 6

    A point in between. Put the timeline in the middle of the walk, grab the figure and drag it aside: a new navgoal is created at that moment, and the figure walks there first.

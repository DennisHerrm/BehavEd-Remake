    Reference

    Glossary

    The words of Jedi Academy scripting in one place.

    TermMeaning
    ICARUSThe scripting system of the game. Scripts are text (.txt) and run compiled (.ibi).
    .ibiA compiled script - what the game actually runs. Compile! makes it.
    .bhcThe command description file: every command, its fields and their choices.
    affectA block whose commands go to one named figure or entity.
    task / do / dowaitA named group of commands; do starts it alongside, dowait waits until it is done.
    waitA pause in milliseconds. In the game it ends one frame (50 ms) later than written.
    SET_NAVGOALSends a figure walking to a waypoint_navgoal.
    NPC_spawnerThe entity that makes a character appear; NPC_type says which one, NPC_targetname names it for scripts.
    ref_tagA named mark in the map - for camera positions and look targets.
    target_scriptrunnerRuns a script when it is used (by a trigger, another entity or a script).
    func_staticA brush model of the map that scripts can move - ships, doors, platforms.
    ROFF (.rof)A recorded movement: one small step of position and angle per game frame. See How ROFF files work.
    .pk3A zip archive the game reads its files from. A mission is packed into one.
    .entThe entities of a map in a separate file; Movie Duels keeps the map and puts its own entities next to it.
    Movie DuelsA large Jedi Academy mod with cutscene missions - the main use of this program.

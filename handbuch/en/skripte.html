Scripts

Writing scripts

An ICARUS script is a tree of commands. Pick commands from the list, put them in the right block, fill in their values.

How a script is built#

Commands run from top to bottom. affect ( "name", FLUSH ) { ... } sends the commands inside it to one figure or entity - that is how a cutscene moves its actors. task declares a group of commands, do starts it alongside, dowait waits for it, wait pauses. if, else, loop work as in other languages. Only affect, task, if, else and loop can hold commands.

Adding commands#

  • In the Events list on the left, double-click a command to insert it after the selected line (or into the selected block).
  • Or drag it into the tree: where you let go decides whether it lands before, inside or after a line.
  • Macros at the end of the list insert several commands at once; Fold Macros shows them as one line.
  • Right-click a line for the same lists as submenus, plus edit, copy and Find similar.

The event editor#

Double-click a line (or press Enter) to open the Event editor. The help text of the command stands on top, each value has its own field below: lists for fixed choices, number and text fields, file fields with to browse and Do to play a sound or open a script. When a map is loaded, an arrow next to name fields picks a name from the map.

  • Expr! turns a field into a free expression; Helper builds get ( ... ), tag ( ... ) or random ( ... ) with Get, Tag and Rnd; Revert goes back.
  • A value that is not in its list is allowed - mods bring their own - but marked unknown, because far more often it is a typo.
  • Ok (Enter) writes the values, Cancel (Esc) drops them, Re-Evaluate resets the fields to the defaults.

Selecting, moving, copying#

  • Click selects a line, Ctrl+click adds one, Shift+click selects a range. Every action works on everything selected.
  • Drag lines to move them. Blocks move with everything inside; a block cannot go into itself.
  • Copy, Cut, Paste - pasting into a block puts the commands in exactly once, also when the block and its lines were copied together.
  • Duplicate inserts a copy right below, REM turns lines into comments and back, Delete removes them.
  • Undo and Redo remember every step. Right-click either button for the full history - you can even undo one single step and keep everything after it.

Find, replace, bookmarks#

Find (Ctrl+F) opens a window that stays open: search by command name (Item called) or by a value (Item containing), step with F3 / Shift+F3, replace in this script or in all open ones. Bookmarks work like Notepad++: Ctrl+F2 sets one, F2 jumps to the next. They are kept per file.

The change margin#

With View → Change history (margin) a coloured margin marks what you changed: orange = changed, not saved; green = changed and saved; blue = back to the original. Hover it to see the original line, right-click a line → Revert to original to restore just that command.

Reference

Keyboard shortcuts

The default keys. Most of them can be changed under Edit → Keyboard shortcuts.

Script#

EnterEdit the selected command
InsertInsert the command selected in the Events list
DeleteDelete
SpaceDuplicate
Ctrl + CCopy
Ctrl + XCut (also Ctrl+T)
Ctrl + VPaste
BackspaceREM: comment out / back (Ctrl+Backspace: uncomment)
Alt + UpMove up (Alt+Down: down), staying in the block
Ctrl + ZUndo (Ctrl+Y or Ctrl+Shift+Z: redo)
Ctrl + FFind; F3 / Shift+F3 next / previous
Ctrl + F2Toggle bookmark; F2 / Shift+F2 next / previous
Num+Expand item and children (Ctrl+Num+: all)
Num-Collapse item (Ctrl+Num-: all)

Files#

Ctrl + OOpen
Ctrl + SSave
Ctrl + ASave as (as in the original BehavEd)
Ctrl + Shift + SSave all
Alt + BBackup; Alt+R restore
Alt + MRecently opened files
Alt + PPrefs; Alt+X exit

Map and camera#

W A S DFly (mouse over the view); Q / E down / up, Shift faster; right mouse looks around
Ctrl + 1Save view 1 (… 9); 1 … 9 jumps back
CtrlWhile dragging an entity: rings in 15-degree steps; with a grid set it turns the grid off, without one an arrow snaps to 8 units
AltAlt+drag an entity: copy it first
ShiftWhile dragging a flight target or a key diamond: only up and down
EscCancel placing, the waypoint tool or piloting
EnterWhile piloting: set a camera key at the playhead

Timeline#

Left / Right50 ms back / forward, mouse over the timeline (Shift: 1 s)
Home / EndJump to start / end (mouse over the timeline)
AltWhile dragging a block: move only this block

Window#

Ctrl + wheelInterface size (over the timeline tracks: zoom the timeline)

Missions

Missions

A mission is a map with its entities and all its scripts. Open one whole, build your own, and pack it into a .pk3 that the game loads.

Opening a mission#

Load mission (menu File or the map toolbar) picks a .pk3 and lists the missions in it - the maps that have scripts. Pick one and everything is set up: the map, its .ent with the mission's figures, and every script of the mission in its own tab; the first script - usually the intro - is in front. All tabs share the map and the camera.

Recent missions#

File → Recent missions and the start page list the missions you opened last - from an archive or from a mission folder. One click opens the whole project again: map, entities and all scripts. An entry whose file is gone is removed from the list.

A new mission#

New mission starts a mission on any map. Choose the map, give the mission a name (letters, digits and _; the game loads it as maps/<name>.bsp, so devmap <name>), and a script folder. BehavEd-Remake creates a player start, a script runner, the intro script and a mission folder under Documents\behaved\missions. The intro runs when the player spawns.

A mission that was never packed lives in its folder; Open mission folder continues it after a restart.

Saving a mission#

Save mission shows what will go into the archive - every file with its size - and checks the mission first: a script that an entity uses but that does not exist, a script that does not compile, no player start, a target that points nowhere, a .str without ENDMARKER. Errors (red) must be fixed, warnings (orange) may stay. Save saves all scripts, writes the .ent, compiles the scripts, adds your own ROFF files and packs the .pk3 into the game folder.

No.NameWhat it does
1Game archive (.pk3)Where the .pk3 is written; Choose picks another place.
2Save / CancelSaves, compiles and packs - or closes the window. Above them: every file of the package and the checks.
The archive goes into the game folder that wins - the bottom one under Edit → Game folders - as zz_<name>.pk3, so it wins over older files. Start the game and type devmap <name> in the console to play it.

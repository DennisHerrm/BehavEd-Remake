The window

One window, three modes. The mode bar on the left decides what the big area shows; script, map and timeline always talk to each other.

The parts#

PartWhat it is for
Menu barFile, Edit, Debug, View, Help - opening and saving, game folders, look and language, the guide.
Script tabsOne tab per open script. A * means unsaved changes, + opens a new script, tabs can be dragged into another order. All tabs of a mission share the map and the camera.
Mode barThe strip at the far left: Events (build scripts), Map (the 3D map), Model (look at a character model).
Left columnDepends on the mode: the list of commands, the entities of the map with their inspector, or the animations of a model.
Script FlowThe script itself - as a tree (Classic), a graph (Graph) or over time (Tracks). See Script Flow: Classic, Graph, Tracks.
ActionsThe button column on the right, as in the original: edit, file, tree options, Compile!. In Map mode it makes room for the map.
TimelineUnder the map: plays the scene and shows every command in time. See Timeline.
Status lineMessages, the error and note counters (click them for the list), the undo history and when the script was last compiled.

Two scripts side by side#

File → Split view shows up to four scripts beside each other in Events mode - for comparing and for copying commands across. Drag a command from one pane into another to copy it; click into a pane to work in it.

Size, look and layout#

  • Ctrl + mouse wheel scales the whole interface (50 - 300 %); View → Interface Scale does the same.
  • View → Theme: BehavEd Classic, Windows, Dark, Midnight, Light, High Contrast.
  • Drag the borders between the columns to resize them; each mode remembers its widths. Debug → Restore default layout puts everything back.
  • Opening a file in Explorer while BehavEd-Remake runs hands it to the open window instead of starting a second program.

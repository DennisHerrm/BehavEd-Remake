Script Flow: Classic, Graph, Tracks

Three views of the same script - switch any time, nothing is lost.

The buttons Classic / Graph / Tracks at the top of the Script Flow column switch the view. In a split view every pane has its own.

Classic#

The tree of the original BehavEd - every command one line, blocks to fold open; see Writing scripts. Since rc601 you can build and change a script in every view - the tutorials on scripts have a switch at the top that shows their steps for Classic, Graph or Tracks.

Graph: what starts what#

A mission is held together by its entities: a trigger targets a target_scriptrunner, which runs a script, which affects figures and starts other scripts. The graph draws exactly that. Double-click a node to open its script or show the entity in the map; drag from the dot on the right of a node to another node to connect them - for a figure you choose what kind of script (spawnscript, deathscript, ...). Drag entities from the list or commands into the graph; a command dropped on free space creates a new script.

Fit shows everything, Arrange sorts the nodes, Right angles draws the wires at right angles through the gaps. Double-click a wire for a bend point; right-click removes it.

Editing in the Graph. Click a script node: on the right, Commands of this script lists every command of the script, blocks indented. Click a line to select it, double-click to open the editor, right-click for the same menu as in Classic (edit, duplicate, copy, cut, paste, move, REM, delete, insert). A command from the Events list dropped on a line goes after it; double-clicking a command in the list inserts it after the selected line. A script that is not open shows Edit here.

Tracks: the script over time#

A compact timeline inside the script column: rows for Camera, every figure, Dialogue (voice lines) and Script. Click a block to select its line, drag its right edge to change the duration, drag in the ruler to move through time. The big Timeline under the map does the same with more detail.

Editing in Tracks. Double-click a block to open the editor; right-click it for the menu of the Classic line. Drag a command from the Events list into a row: a yellow line shows the moment, and the command goes after the last command of that row that starts before it - in a figure's row, inside that figure's affect block. On the right, Command list lists every command, also those that take no time (affect, task, declare) and an empty script - it works like the list in the Graph. Switch it off with the checkbox to give the timeline the whole width.

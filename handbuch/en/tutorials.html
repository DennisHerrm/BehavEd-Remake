Start with the Taspir mission - it builds a whole cutscene for Jedi Academy from nothing and touches almost every part of the program. The short tutorials below each show one thing in a few steps.

Interactive tutorials in the program#

Some tutorials also run inside the program: Help → Interactive tutorials (or Interactive tour on the start page) opens a small window with the list. Pick one and press Start: the program darkens the screen except for the control you need, frames it in yellow and moves on by itself as soon as you have done the step - whether you used the button, the menu or the shortcut.

  • Back goes one step back. Skip skips a step - where it can, the program prepares the next one (it never changes your script). Next moves on after a step that only shows something.
  • Show me moves a pointer to the right place; nothing is clicked. Do it for me does the step for you - offered only where that is safe, never for saving (which asks for a file name).
  • Open this page in the guide opens the page with its pictures in your browser. The search box below the list searches this guide, offline.
  • The program remembers how far you got; next time you continue where you stopped.
  • The first five are the script tutorials Write a script from scratch, Three ways to add a command, Change the values of a command, Move, copy and comment out lines and Compile and fix errors, in the Classic view.

The big one: your own mission#

Your own mission: take-off on Taspir

A complete little mission for Jedi Academy, built from nothing: Kyle and Rosh walk across a landing pad, the camera follows them, the Raven's Claw lifts off and flies past the camera, the picture shakes and fades to black - and the game plays it.

Eight parts · base game · about 30 minutes

All tutorials use the base game - the map taspir1 and its characters - so the pictures match what you see. Any other map, and any mod such as Movie Duels, works the same way. If the parts of the window are new to you, read The window and Moving around first.

Saving, compiling, checks

The game runs .ibi files. You write .txt; Compile! makes the .ibi - byte for byte like Raven's IBIZE.

Saving#

  • Save (Ctrl+S) always writes the .txt source - also when you opened an .ibi (it lands next to it).
  • Save all (Ctrl+Shift+S) saves every tab with changes; tabs from an archive have no file to write back to and are skipped.
  • Every save and compile keeps a copy - backup1.txt (newest) to backup10.txt - in the backup folder next to behaved.exe, one subfolder per script; File → Open backup folder shows them. Backup / Restore keep and restore one extra copy (<script>.bak next to the script) by hand.
  • Own ROFF paths are written as .rof files together with the script - see How ROFF files work.

Compiling#

Compile! in the action column writes <script>.ibi next to the .txt (and saves the .txt). The button flashes green with Compiled, or red with Failed - then the first bad line is selected and the status line says why. The compiler is built in and was checked against 1011 .ibi files from Raven's IBIZE, byte for byte.

Notes and errors#

While you write, the program checks every line: unknown commands, values that are not in their list, a text field without quotes, a misspelled field ("did you mean ...?"). The counters in the status line show how many there are - click them for the list, click a message to jump to its line. View → Target game adds notes on what does not work on a multiplayer server.

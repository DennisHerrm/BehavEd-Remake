7 · A second script

Kyle gets a spawn script with a macro - and the split view shows both scripts side by side.

Steps#

  1. 1

    A spawnscript key. Select Kyle, add the key spawnscript with the value taspir_tut/kyle_spawn (+ Key in the inspector).

  2. 2

    Open creates it. Press Open next to the key: the script does not exist yet, so behaved creates it in the mission folder and opens it in a tab.

  3. 3

    A macro. Double-click standOnly at the end of the Events list: three set commands that make Kyle stand and ignore enemies. Add set ( SET_WEAPON, WP_SABER ).

  4. 4

    Side by side. File → Split view → 2 shows the intro beside the spawn script. Drag lines from one to the other to copy them.

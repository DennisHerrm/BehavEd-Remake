Befehle
  • Befehle einzeln
  • affect - Befehle für eine Entity
  • flush - wartende Befehle vergessen
  • if - nur wenn eine Bedingung stimmt
  • else - sonst
  • loop - einen Block wiederholen
  • run - ein anderes Skript starten
  • wait - eine Zeit lang pausieren
  • wait - bis ein Task fertig ist
  • waitsignal - auf ein anderes Skript warten
  • signal - ein wartendes Skript wecken
  • sound - einen Klang oder einen Satz abspielen
  • move - eine Entity bewegen
  • rotate - eine Entity drehen
  • use - eine Entity benutzen
  • kill - eine Entity töten
  • remove - eine Entity aus dem Spiel nehmen
  • print - Text auf dem Bildschirm
  • rem - ein Kommentar
  • declare - eine Variable anlegen
  • free - eine Variable zurückgeben
  • set - ein Feld einer Entity ändern
  • set - eine Variable ändern
  • task - eine benannte Gruppe von Befehlen
  • do - einen Task starten
  • dowait - einen Task starten und auf ihn warten
  • play - eine ROFF-Datei abspielen
  • camera ENABLE - die Zwischensequenz beginnt
  • camera DISABLE - zurück ins Spiel
  • camera MOVE - die Kamera setzen oder fliegen lassen
  • camera PAN - die Kamera drehen
  • camera ZOOM - den Bildwinkel ändern
  • camera ROLL - das Bild kippen
  • camera TRACK - eine Kamerabahn abfahren
  • camera FOLLOW - Figuren im Blick behalten
  • camera DISTANCE - Abstand halten
  • camera FADE - zu einer Farbe hin oder von ihr weg blenden
  • camera SHAKE - das Bild wackeln lassen
  • camera PATH - eine aufgezeichnete Bahn fliegen

Tastenkürzel

Die vorgegebenen Tasten. Die meisten lassen sich unter Bearbeiten → Tastenkürzel ändern.

Skript#

EnterGewählten Befehl bearbeiten
EinfgDen in der Ereignisliste gewählten Befehl einfügen
EntfLöschen
LeertasteDuplizieren
Strg + CKopieren
Strg + XAusschneiden (auch Strg+T)
Strg + VEinfügen
RücktasteREM: auskommentieren / zurück (Strg+Rücktaste: Kommentar entfernen)
Alt + ObenNach oben (Alt+Unten: nach unten), im selben Block
Strg + ZRückgängig (Strg+Y oder Strg+Umschalt+Z: wiederholen)
Strg + FSuchen; F3 / Umschalt+F3 nächster / voriger
Strg + F2Lesezeichen setzen; F2 / Umschalt+F2 nächstes / voriges
Num+Eintrag und Kinder aufklappen (Strg+Num+: alles)
Num-Eintrag zuklappen (Strg+Num-: alles)

Dateien#

Strg + OÖffnen
Strg + SSpeichern
Strg + ASpeichern unter (wie im Original-BehavEd)
Strg + Umschalt + SAlle speichern
Alt + BSicherung; Alt+R wiederherstellen
Alt + MZuletzt geöffnete Dateien
Alt + PEinstellungen; Alt+X beenden

Karte und Kamera#

W A S DFliegen (Maus über der Ansicht); Q / E runter / hoch, Umschalt schneller; rechte Maus schaut umher
Strg + 1Ansicht 1 merken (… 9); 1 … 9 springt zurück
StrgBeim Ziehen einer Entity: Ringe in 15-Grad-Schritten; mit eingestelltem Raster schaltet es das Raster aus, ohne rastet ein Pfeil auf 8 Einheiten
AltAlt+Ziehen einer Entity: erst kopieren
UmschaltBeim Ziehen eines Flugziels oder einer Schlüsselraute: nur hoch und runter
EscPlatzieren, Wegpunktwerkzeug oder Steuern abbrechen
EnterBeim Steuern: Kameraschlüssel am Zeiger setzen

Zeitleiste#

Links / Rechts50 ms zurück / vor, Maus über der Zeitleiste (Umschalt: 1 s)
Pos1 / EndeZum Anfang / Ende (Maus über der Zeitleiste)
AltBeim Ziehen eines Blocks: nur diesen Block verschieben

Fenster#

Strg + MausradOberflächengröße (über den Spuren der Zeitleiste: die Zeitleiste zoomen)

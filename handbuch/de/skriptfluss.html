Script Flow: Classic, Graph, Spuren

Drei Ansichten desselben Skripts - jederzeit umschaltbar, nichts geht verloren.

Die Knöpfe Classic / Graph / Spuren oben in der Spalte Skriptablauf schalten die Ansicht. In einer geteilten Ansicht hat jedes Feld seine eigene.

Classic#

Der Baum des Original-BehavEd - jeder Befehl eine Zeile, Blöcke zum Aufklappen. Hier wird bearbeitet; siehe Skripte schreiben.

Graph: was startet was#

Eine Mission wird von ihren Entities zusammengehalten: ein trigger zielt auf einen target_scriptrunner, der ein Skript startet, das Figuren steuert und andere Skripte startet. Genau das zeichnet der Graph. Doppelklick auf einen Knoten öffnet sein Skript oder zeigt die Entity in der Karte; vom Punkt rechts an einem Knoten zu einem anderen ziehen verbindet sie - bei einer Figur wählst du die Art des Skripts (spawnscript, deathscript, ...). Entities aus der Liste oder Befehle lassen sich in den Graphen ziehen; ein Befehl auf freier Fläche legt ein neues Skript an.

Einpassen zeigt alles, Anordnen ordnet die Knoten, Rechtwinklig zieht die Leitungen rechtwinklig durch die Lücken. Doppelklick auf eine Leitung setzt einen Umlenkpunkt; Rechtsklick entfernt ihn.

Spuren: das Skript über die Zeit#

Eine kompakte Zeitleiste in der Skriptspalte: Zeilen für Kamera, jede Figur, Dialog (Sprachzeilen) und Skript. Klick auf einen Block wählt seine Zeile, seinen rechten Rand ziehen ändert die Dauer, im Lineal ziehen bewegt durch die Zeit. Die große Zeitleiste unter der Karte tut dasselbe genauer.

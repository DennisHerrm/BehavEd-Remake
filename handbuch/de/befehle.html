Alle Befehle

Was jeder Befehl der Ereignisliste tut, jeder Kamerabefehl, jedes Makro und jedes SET_-Feld - mit dem Wert, den er erwartet.

Befehle fügst du aus der Liste Ereignisse ein (Doppelklick, Ziehen oder Einfg) und änderst sie im Ereignis-Editor (Doppelklick auf die Zeile). Fährst du in der Liste mit der Maus über einen Befehl, siehst du den Hilfetext, den die Entwickler des Spiels dafür geschrieben haben. Wie man sie zusammensetzt: Skripte schreiben.

Die Befehle der Ereignisliste#

Jeder Befehl hat eine eigene Seite mit Bildern des Editors und aller drei Ansichten: Befehle einzeln.

BefehlWas er tutBeispiel
flushLöscht jeden Befehl, der für diese Entity noch wartet - das, was ein affect-Block mit FLUSH an seinem Anfang tut.flush ( )
if / elseFührt den Block nur aus, wenn der Vergleich stimmt (=, <, >, ! für *ungleich*). else muss direkt auf ein if folgen.if ( $get( FLOAT, "count")$, $>$, $2$ )
loopWiederholt seinen Block; die Zahl sagt, wie oft, -1 heißt endlos.loop ( 3 )
affectSchickt die Befehle seines Blocks über ihren Namen an eine Entity - eine Figur, ein Schiff, eine Tür. FLUSH ersetzt, was die Entity gerade tat, INSERT fügt es hinzu. Das Skript selbst wartet nicht auf den Block.affect ( "kyle", FLUSH )
runStartet ein anderes Skript auf der Entity, die dieses Skript ausführt.run ( "taspir_tut/kyle_spawn" )
waitPausiert so viele Millisekunden - oder, mit einem Namen, bis diese Aufgabe fertig ist.wait ( 2000 )
waitsignalPausiert, bis ein anderes Skript signal mit demselben Namen aufruft. Auf ein bestimmtes Signal kann nur ein Skript warten.waitsignal ( "door_open" )
signalWeckt das Skript, das auf diesen Namen wartet.signal ( "door_open" )
soundSpielt einen Klang auf einem Kanal der Entity - CHAN_VOICE für Dialog, damit sich der Mund bewegt.sound ( CHAN_VOICE, "sound/chars/kyle/..." )
moveBewegt eine Entity (eine Tür, eine Plattform, ein Schiff) in so vielen Millisekunden an einen Ort - und, falls angegeben, auf neue Winkel. Das Animate-Fenster schreibt das für dich (Eine Tür, die sich öffnet).move ( < 0 0 128 >, < 0 0 0 >, 2000 )
rotateDreht eine Entity in so vielen Millisekunden auf Winkel (Nicken, Gieren, Rollen).rotate ( < 0 90 0 >, 1000 )
useBenutzt eine Entity über ihren Namen, als hätte der Spieler sie betätigt - öffnet eine Tür, löst einen Trigger aus.use ( "door1" )
killTötet die Entity mit diesem Namen.kill ( "stormie1" )
removeEntfernt die Entity mit diesem Namen aus dem Spiel.remove ( "stormie1" )
printZeigt einen Text in der Bildmitte.print ( "Hello" )
remEin Kommentar - tut im Spiel nichts. Auskommentieren macht aus jeder Zeile einen.rem ( "camera starts here" )
declare / freeLegt eine Variable an (FLOAT, STRING, VECTOR; höchstens 16 pro Karte) - free gibt den Namen wieder frei.declare ( FLOAT, "count" )
setÄndert einen Wert: ein Entity-Feld (SET_NAVGOAL, SET_ANIM_BOTH, ... - siehe die vollständige Liste unten) oder eine angelegte Variable.set ( SET_WALKING, "true" )
cameraSteuert die Kamera der Zwischensequenz; der erste Wert wählt, was sie tut - siehe nächster Abschnitt.camera ( ENABLE )
taskLegt eine benannte Gruppe von Befehlen an - sie läuft noch nicht.task ( "walk" )
doStartet eine Aufgabe und macht sofort weiter.do ( "walk" )
dowaitStartet eine Aufgabe und wartet, bis sie fertig ist - bei einem Gang: bis die Figur angekommen ist.dowait ( "walk" )
playSpielt eine ROFF-Datei auf der Entity des aktuellen affect-Blocks ab - eine aufgezeichnete Bewegung.play ( PLAY_ROFF, "taspir_tut/roffs/ravensClaw" )
Ein Befehl, der in seinem Hilfetext mit * markiert ist (zum Beispiel SET_NAVGOAL), beendet seine Aufgabe erst, wenn die Handlung fertig ist - deshalb kann dowait auf ihn warten.

camera ( ... ) - die Kamerabefehle#

Der erste Wert von camera wählt den Befehl. behaved zeigt jeden davon in der Zeitleiste unter Kamera und spielt ihn in der Ansicht ab. Zeiten sind in Millisekunden.

BefehlWerteWas er tut (Hilfetext des Spiels)
ENABLE-Schaltet das Spiel in den Kameramodus
DISABLE-Holt das Spiel aus dem Kameramodus
ZOOMZahl, GanzzahlNormal ist 80, 10 ist herangezoomt, Maximum ist 120. Der zweite Wert ist die Zeit in ms, um auf das neue FOV zu zoomen
MOVEVektor, GanzzahlFährt über die angegebene Zahl Millisekunden zu einem absoluten Vektor-Ursprung oder TAG("targetname", ORIGIN)
PANVektor, Vektor, GanzzahlSchwenkt über die angegebene Zahl Millisekunden vom aktuellen Winkel auf einen absoluten Winkel, in Richtung dir (ohne dir der kürzeste Weg)
ROLLZahl, GanzzahlRollt über die angegebene Zahl Millisekunden um Winkelversätze relativ zum aktuellen Winkel
TRACKText, Zahl, GanzzahlAuf die Spur gehen und mit dieser Geschwindigkeit fahren; die letzte Zahl sagt, ob zur Startposition übergeblendet (lerp) wird
FOLLOWText, Zahl, GanzzahlFolgt Ents mit passender cameraGroup mit angleSpeed; die letzte Zahl sagt, ob zum Startwinkel übergeblendet (lerp) wird
DISTANCEZahl, GanzzahlHält diesen Abstand zur cameraGroup (falls vorhanden); die letzte Zahl sagt, ob zum Startwinkel übergeblendet (lerp) wird
FADEVektor, Zahl, Vektor, Zahl, GanzzahlBlendet von [Start Rot Grün Blau], [Deckkraft] zu [Ende Rot Grün Blau], [Deckkraft] (gültiger Bereich aller Felder: 0 bis 1) über [Anzahl Millisekunden]
SHAKEZahl, GanzzahlStärke (0-16) und Dauer in Millisekunden
PATHTextPfad zur ROF-Datei

Ausdrücke: get, tag, random#

Statt eines festen Werts kann ein Feld einen Ausdruck enthalten. Im Editor baut Helfer sie:

  • Get - get ( FLOAT, "name" ) liest eine mit declare angelegte Variable.
  • Tag - tag ( "cam_door", ORIGIN ) nimmt die Position (oder ANGLES) eines ref_tag auf der Karte. So stehen Kameras auf Markierungen.
  • Rnd - random ( 1000, 3000 ) ist eine Zufallszahl zwischen zwei Werten, zum Beispiel für ein wait.

Every command

What each command of the Events list does, every camera command, every macro and every SET_ field - with the value it expects.

Commands are inserted from the Ereignisse list (double-click, drag or Insert) and changed in the Ereignis-Editor (double-click the line). Hover over a command in the list to read the help text the game's designers wrote for it. How to put them together: Skripte schreiben.

The commands of the Events list#

CommandWhat it doesExample
flushClears every command still waiting for this entity - what an affect block with FLUSH does at its start.flush ( )
if / elseRuns the block only if the comparison holds (=, <, >, ! for *not equal*). else must follow right after an if.if ( $get( FLOAT, "count")$, $>$, $2$ )
loopRepeats its block; the number says how often, -1 means forever.loop ( 3 )
affectSends the commands of its block to one entity - a figure, a ship, a door - by its name. FLUSH replaces what the entity was doing, INSERT adds to it. The script itself does not wait for the block.affect ( "kyle", FLUSH )
runStarts another script on the entity that runs this one.run ( "taspir_tut/kyle_spawn" )
waitPauses for so many milliseconds - or, with a name, until that task is finished.wait ( 2000 )
waitsignalPauses until some other script calls signal with the same name. Only one script can wait for a given signal.waitsignal ( "door_open" )
signalWakes the script that waits for this name.signal ( "door_open" )
soundPlays a sound on a channel of the entity - CHAN_VOICE for dialogue, so the mouth moves.sound ( CHAN_VOICE, "sound/chars/kyle/..." )
moveMoves an entity (a door, a platform, a ship) to a position - and, if given, to new angles - in so many milliseconds. The Animate window writes these for you (A door that opens).move ( < 0 0 128 >, < 0 0 0 >, 2000 )
rotateTurns an entity to angles (pitch, yaw, roll) in so many milliseconds.rotate ( < 0 90 0 >, 1000 )
useUses an entity by name, as if the player pressed it - opens a door, fires a trigger.use ( "door1" )
killKills the entity with this name.kill ( "stormie1" )
removeRemoves the entity with this name from the game.remove ( "stormie1" )
printShows a text in the middle of the screen.print ( "Hello" )
remA comment - does nothing in the game. Auskommentieren turns any line into one.rem ( "camera starts here" )
declare / freeDeclares a variable (FLOAT, STRING, VECTOR; at most 16 per map) - free gives the name back.declare ( FLOAT, "count" )
setChanges a value: an entity field (SET_NAVGOAL, SET_ANIM_BOTH, ... - see the full list below) or a declared variable.set ( SET_WALKING, "true" )
cameraControls the cutscene camera; the first value chooses what it does - see the next section.camera ( ENABLE )
taskDeclares a named group of commands - it does not run yet.task ( "walk" )
doStarts a task and goes on at once.do ( "walk" )
dowaitStarts a task and waits until it is done - for a walk: until the figure has arrived.dowait ( "walk" )
playPlays a ROFF file on the entity of the current affect block - a recorded movement.play ( PLAY_ROFF, "taspir_tut/roffs/ravensClaw" )
A command marked with * in its help text (for example SET_NAVGOAL) finishes its task only when the action is done - that is what lets dowait wait for it.

camera ( ... ) - the camera commands#

The first value of camera chooses the command. behaved shows every one of them in the timeline under Kamera and plays it in the view. Times are in milliseconds.

CommandValuesWhat it does (help text of the game)
ENABLE-Puts game in camera mode
DISABLE-Takes game out of camera mode
ZOOMnumber, whole numberNormal is 80, 10 is zoomed in, max is 120. Second value is time in ms to take to zoom to the new FOV
MOVEvector, whole numberMove to a absolute vector origin or TAG("targetname", ORIGIN) over time over number of milliseconds
PANvector, vector, whole numberPan to absolute angle from current angle in dir (no dir will use shortest) over number of milliseconds
ROLLnumber, whole numberRoll to relative angle offsets of current angle over number of milliseconds
TRACKtext, number, whole numberGet on track and move at speed, last number is whether or not to lerp to the start pos
FOLLOWtext, number, whole numberFollow ents with matching cameraGroup at angleSpeed, last number is whether or not to lerp to the start angle
DISTANCEnumber, whole numberKeep this distance from cameraGroup (if any), last number is whether or not to lerp to the start angle
FADEvector, number, vector, number, whole numberFade from [start Red Green Blue], [Opacity] to [end Red Green Blue], [Opacity] (all fields valid ranges are 0 to 1) over [number of milliseconds]
SHAKEnumber, whole numberIntensity (0-16) and duration, in milliseconds
PATHtextPath to ROF file

Expressions: get, tag, random#

Instead of a fixed value, a field can hold an expression. In the editor, Helfer builds them:

  • Get - get ( FLOAT, "name" ) reads a variable declared with declare.
  • Tag - tag ( "cam_door", ORIGIN ) takes the position (or ANGLES) of a ref_tag on the map. That is how cameras stand on marks.
  • Rnd - random ( 1000, 3000 ) a random number between two values, for example a wait.

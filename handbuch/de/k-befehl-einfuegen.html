Drei Wege, einen Befehl einzufügen

Doppelklick, Ziehen und Ablegen oder die Einfg-Taste - und wie ein Befehl genau dort landet, wo du ihn haben willst.

Ansicht:

Schritte#

  1. 1

    Doppelklick. Wähle die Zeile, nach der der Befehl kommen soll (1), und doppelklicke dann den Befehl in der Liste Ereignisse (2). Die neue Zeile erscheint direkt unter der gewählten - hier ein wait nach camera ( MOVE ). So hat es schon das Original-BehavEd gemacht.

  2. 2

    Einfg-Taste. Klick einmal auf einen Befehl in der Liste - er bleibt markiert (1). Wähle eine Zeile im Baum (2) und drück Einfg. Praktisch, wenn du denselben Befehl mehrmals einfügst: wählen, Einfg, wählen, Einfg ...

  3. 3

    Ziehen. Zieh einen Befehl aus der Liste (1) auf eine Zeile des Baums (2). Beim Ziehen zeigt eine Linie, wo er landet: über einer Zeile, darunter oder - auf der Mitte eines aufgeklappten Blocks - im Block.

  4. 4

    Rechtsklick. Klick mit rechts auf eine Zeile im Baum: die Untermenüs Ereignisse und Makros listen jeden Befehl; der angeklickte wird nach dieser Zeile eingefügt - oder in den Block, wenn du mit rechts auf einen aufgeklappten Block geklickt hast.

  1. 1

    Wo die Befehle sind. Klick in Graph auf einen Skriptknoten (anfangs ist das offene Skript gewählt). Rechts unter Befehle dieses Skripts steht jeder Befehl dieses Skripts - Blöcke eingerückt. Ein Klick auf eine Zeile wählt sie, ein Doppelklick bearbeitet sie, ein Rechtsklick öffnet das Menü.

  2. 2

    Doppelklick in der Liste Ereignisse. Klick rechts auf eine Zeile (1), dann Doppelklick auf einen Befehl in der Liste Ereignisse (2). Er wird hinter dieser Zeile eingefügt - in den Block, wenn die Zeile ein offener Block ist.

  3. 3

    Auf eine Zeile ziehen. Zieh einen Befehl aus der Liste Ereignisse (1) auf eine Zeile von Befehle dieses Skripts (2): Er landet direkt hinter dieser Zeile.

  4. 4

    Auf den Knoten ziehen. Lässt du den Befehl auf einem Skriptknoten im Graphen (2) fallen, kommt er ans Ende dieses Skripts. Auf freier Fläche fallen gelassen, beginnt er ein neues Skript.

  5. 5

    Rechtsklick. Rechtsklick rechts auf eine Zeile: Die Untermenüs Ereignisse und Makros fügen hinter dieser Zeile ein - dasselbe Menü wie in Classic.

  1. 1

    Wo die Befehle sind. Spuren zeigt das Skript über die Zeit: die Kamera, eine Zeile je Figur, die Wartezeiten. Rechts listet Befehlsliste jeden Befehl - auch die, die keine Zeit brauchen, etwa affect, task oder declare.

  2. 2

    Doppelklick in der Liste Ereignisse. Klick auf einen Block oder eine Zeile der Liste (1), dann Doppelklick auf einen Befehl in der Liste Ereignisse (2). Er kommt direkt hinter den gewählten Befehl.

  3. 3

    In eine Zeile an einen Zeitpunkt ziehen. Zieh einen Befehl aus der Liste Ereignisse (1) in eine Zeile der Zeitleiste (2). Eine gelbe Linie zeigt den Zeitpunkt. Der Befehl kommt hinter den letzten Befehl dieser Zeile, der vor der Linie beginnt - in der Zeile einer Figur in deren affect-Block.

  4. 4

    In die Liste ziehen. Befehle ohne Zeit - ein affect, ein task, ein declare - ziehst du in die Liste rechts (2): hinter die Zeile, auf der du loslässt, oder auf freier Fläche ans Ende.

  5. 5

    Rechtsklick. Rechtsklick auf einen Block (oder eine Zeile der Liste): Ereignisse und Makros fügen dahinter ein.

Gut zu wissen#

  • Fahr mit der Maus über einen Befehl in der Liste, um zu lesen, was er tut.
  • Makros am Ende der Liste fügen mehrere Befehle auf einmal ein, zum Beispiel walkOnly.

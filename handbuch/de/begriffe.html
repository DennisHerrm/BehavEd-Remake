    Befehle
    • Befehle einzeln
    • affect - Befehle für eine Entity
    • flush - wartende Befehle vergessen
    • if - nur wenn eine Bedingung stimmt
    • else - sonst
    • loop - einen Block wiederholen
    • run - ein anderes Skript starten
    • wait - eine Zeit lang pausieren
    • wait - bis ein Task fertig ist
    • waitsignal - auf ein anderes Skript warten
    • signal - ein wartendes Skript wecken
    • sound - einen Klang oder einen Satz abspielen
    • move - eine Entity bewegen
    • rotate - eine Entity drehen
    • use - eine Entity benutzen
    • kill - eine Entity töten
    • remove - eine Entity aus dem Spiel nehmen
    • print - Text auf dem Bildschirm
    • rem - ein Kommentar
    • declare - eine Variable anlegen
    • free - eine Variable zurückgeben
    • set - ein Feld einer Entity ändern
    • set - eine Variable ändern
    • task - eine benannte Gruppe von Befehlen
    • do - einen Task starten
    • dowait - einen Task starten und auf ihn warten
    • play - eine ROFF-Datei abspielen
    • camera ENABLE - die Zwischensequenz beginnt
    • camera DISABLE - zurück ins Spiel
    • camera MOVE - die Kamera setzen oder fliegen lassen
    • camera PAN - die Kamera drehen
    • camera ZOOM - den Bildwinkel ändern
    • camera ROLL - das Bild kippen
    • camera TRACK - eine Kamerabahn abfahren
    • camera FOLLOW - Figuren im Blick behalten
    • camera DISTANCE - Abstand halten
    • camera FADE - zu einer Farbe hin oder von ihr weg blenden
    • camera SHAKE - das Bild wackeln lassen
    • camera PATH - eine aufgezeichnete Bahn fliegen

    Begriffe

    Die Wörter der Jedi-Academy-Skripte an einem Ort.

    BegriffBedeutung
    ICARUSDas Skriptsystem des Spiels. Skripte sind Text (.txt) und laufen übersetzt (.ibi).
    .ibiEin übersetztes Skript - das, was das Spiel wirklich ausführt. Übersetzen! erzeugt es.
    .bhcDie Befehlsbeschreibung: jeder Befehl, seine Felder und deren Auswahl.
    affectEin Block, dessen Befehle an eine benannte Figur oder Entity gehen.
    task / do / dowaitEine benannte Gruppe von Befehlen; do startet sie nebenher, dowait wartet, bis sie fertig ist.
    waitEine Pause in Millisekunden. Im Spiel endet sie ein Bild (50 ms) später als geschrieben.
    SET_NAVGOALSchickt eine Figur zu einem waypoint_navgoal - gerade, wenn es nah ist, sonst über das Wegnetz. Siehe Wie Figuren sich bewegen - wie im Spiel.
    SET_YAWSPEEDWie schnell ein NPC sich dreht: 60 + 3 × Wert Grad je Sekunde.
    SET_SABERCOLLISIONSNur Movie Duels: lässt die Klingen von NPCs in BS_CINEMATIC klirren. Siehe Lichtschwerter: Wände und Klirren.
    NPC_spawnerDie Entity, die eine Figur erscheinen lässt; NPC_type sagt welche, NPC_targetname benennt sie für Skripte.
    ref_tagEine benannte Marke in der Karte - für Kamerapositionen und Blickziele.
    target_scriptrunnerStartet ein Skript, wenn es benutzt wird (von einem Auslöser, einer anderen Entity oder einem Skript).
    func_staticEin Brush-Modell der Karte, das Skripte bewegen können - Schiffe, Türen, Plattformen.
    ROFF (.rof)Eine aufgezeichnete Bewegung: je Spielbild ein kleiner Schritt in Ort und Winkel. Siehe Wie ROFF-Dateien funktionieren.
    .pk3Ein Zip-Archiv, aus dem das Spiel seine Dateien liest. Eine Mission wird in eines gepackt.
    .entDie Entities einer Karte in einer eigenen Datei; Movie Duels lässt die Karte und legt eigene Entities daneben.
    Movie DuelsEin großer Jedi-Academy-Mod mit Zwischensequenz-Missionen. Sein Spielcode weicht stellenweise von OpenJK ab; die Vorschau folgt wahlweise dem einen oder dem anderen - Einstellungen.

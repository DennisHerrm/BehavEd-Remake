Nur beim ersten Mal: Variablen und if

Merken, dass etwas geschehen ist - eine Variable deklarieren, setzen und mit if abfragen.

Ansicht:

Schritte#

  1. 1

    Deklariere einmal. Füge in einem Skript, das nur einmal läuft - dem Intro, einem Spawn-Skript -, declare ein. Wähle im Editor FLOAT und tippe einen Namen, zum Beispiel seen. Eine deklarierte Variable beginnt bei 0; eine Karte kann 16 davon haben.

  2. 2

    Frag mit if. Füge in dem Skript, das öfter laufen kann, if ein. Drück beim ersten Wert Helfer und bau mit Get get ( FLOAT, "seen" ); als Vergleich =, als anderen Wert 0.

  3. 3

    Im if ausführen - oder im else. Pack die Befehle der Szene in den if-Block. Ein else direkt danach läuft, wenn die Szene schon gesehen wurde.

  4. 4

    Merken. Am Ende des if-Blocks set mit dem Variablennamen seen und dem Wert 1 einfügen - beim nächsten Mal ist das if falsch.

  5. 5

    Freigeben mit free ( "seen" ), wenn sie nicht mehr gebraucht wird - dann ist der Name wieder frei.

  1. 1

    Deklarieren. Wähle die erste Zeile unter Befehle dieses Skripts und doppelklick auf declare in der Liste Ereignisse. Wähle im Editor FLOAT und tippe den Namen seen.

  2. 2

    Mit if fragen. Füge if genauso ein. Im Editor baut Helfer → Get get ( FLOAT, "seen" ); Vergleich =, Wert 0.

  3. 3

    Die Blöcke füllen. Wähle die Zeile if und füge die Befehle der Szene ein - sie kommen in den offenen Block. Ein else direkt nach dem if läuft, wenn die Szene schon einmal gesehen wurde; set ( "seen", "1" ) am Ende des if merkt es sich.

  1. 1

    In der Liste bauen. declare, if und else brauchen keine Zeit - bau sie in der Befehlsliste rechts, genauso wie im Graphen.

  2. 2

    Mit if fragen. Im Editor baut Helfer → Get get ( FLOAT, "seen" ); Vergleich =, Wert 0.

  3. 3

    Was die Zeitleiste zeigt. Die Zeitleiste spielt die Befehle im if ab, als wäre es wahr - sie kann den Wert im Spiel nicht kennen.

Gut zu wissen#

  • Vergleiche sind =, <, > und ! (ungleich) - bei allem anderen warnt behaved.

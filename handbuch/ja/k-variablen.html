最初の 1 回だけ:変数と if

何かが起きたことを覚えておきます。変数を宣言し、設定し、if で問い合わせます。

ビュー:

手順#

  1. 1

    一度だけ宣言します。 一度しか実行されないスクリプト(イントロやスポーンスクリプト)に declare を挿入します。エディターで FLOAT を選び、名前を入力します。たとえば seen です。宣言した変数は 0 から始まり、1 つのマップに 16 個まで置けます。

  2. 2

    if で判定します。 何度も実行される可能性のあるスクリプトに if を挿入します。最初の値で ヘルパー を押し、Get で get ( FLOAT, "seen" ) を作ります。比較演算子は =、もう一方の値は 0 です。

  3. 3

    if の中で実行し、そうでなければ else。 シーンのコマンドを if ブロックに入れます。その直後の else は、シーンをすでに見ているときに実行されます。

  4. 4

    覚えておく。 if ブロックの最後に、変数名 seen、値 1 の set を挿入します。次回は if が偽になります。

  5. 5

    不要になったら free ( "seen" ) で解放します。名前が再び使えるようになります。

  1. 1

    宣言する。 このスクリプトのコマンド の最初の行を選択し、イベント 一覧の declare をダブルクリックします。エディターで FLOAT を選び、名前 seen を入力します。

  2. 2

    if で確かめる。 同じように if を挿入します。エディターで ヘルパー → Get を使うと get ( FLOAT, "seen" ) ができます。比較は =、値は 0 です。

  3. 3

    ブロックを埋める。 if 行を選択してシーンのコマンドを挿入します。開いたブロックの中に入ります。if のすぐ後の else は、シーンを以前に見たことがあるときに実行されます。if の最後の set ( "seen", "1" ) でそれを記憶します。

  1. 1

    一覧で作る。 declare、if、else は時間がかからないので、右のコマンド一覧で作ります。やり方はグラフと同じです。

  2. 2

    if で確かめる。 エディターで ヘルパー → Get を使うと get ( FLOAT, "seen" ) ができます。比較は =、値は 0 です。

  3. 3

    タイムラインに表示されるもの。 タイムラインは if の中のコマンドを、条件が真であるものとして再生します。ゲーム内の値は分からないからです。

知っておくと便利#

  • 比較は =・<・>・!(等しくない)です。それ以外には behaved が警告します。

キーボードショートカット

既定のキーです。ほとんどは 編集 → キーボードショートカット で変更できます。

スクリプト#

Enter選択中のコマンドを編集
Insertイベント一覧で選んだコマンドを挿入
Delete削除
Space複製
Ctrl + Cコピー
Ctrl + X切り取り(Ctrl+T でも可)
Ctrl + V貼り付け
BackspaceREM:コメント化/解除(Ctrl+Backspace:コメント解除)
Alt + Up上へ移動(Alt+Down で下へ)。同じブロック内
Ctrl + Z元に戻す(Ctrl+Y または Ctrl+Shift+Z でやり直し)
Ctrl + F検索。F3 / Shift+F3 で次/前
Ctrl + F2ブックマーク切替。F2 / Shift+F2 で次/前
Num+項目と子を展開(Ctrl+Num+:すべて)
Num-項目を折りたたむ(Ctrl+Num-:すべて)

ファイル#

F1このガイドを開く
Ctrl + O開く
Ctrl + S保存
Ctrl + A名前を付けて保存(オリジナル BehavEd と同じ)
Ctrl + Shift + Sすべて保存
Alt + Bバックアップ。Alt+R で復元
Alt + M最近開いたファイル
Alt + P設定。Alt+X で終了

マップとカメラ#

W A S D飛行(マウスがビュー上)。Q / E で下降/上昇、Shift で高速、右ボタンで見回す
Ctrl + 1視点 1 を保存(…9)。1〜9 で戻る
Ctrlエンティティのドラッグ中:リングは 15 度刻み。グリッド設定時はグリッドを解除、未設定なら矢印が 8 ユニットにスナップ
Altエンティティを Alt+ドラッグ:先にコピー
Shift飛行目標やキーのひし形のドラッグ中:上下のみ
Esc配置・ウェイポイントツール・操縦を取り消す
Enter操縦中:再生位置にカメラキーを設定

タイムライン#

← / →50 ms 戻る/進む。マウスがタイムライン上(Shift:1 秒)
Home / End先頭/末尾へ(マウスがタイムライン上)
Altブロックのドラッグ中:このブロックだけ動かす

ウィンドウ#

Ctrl + ホイールインターフェースの大きさ(タイムラインのトラック上ではタイムラインのズーム)
前へ設定とアップデート次へ用語集

    ミッション

    モデルビューとキャラクター

    ゲームのどのキャラクターでも、スキンとアニメーション付きで表示し、ダブルクリックでアニメーションをスクリプトに入れられます。

    モードバーで モデル に切り替えます。NPC はゲームの全キャラクター(.npc ファイル)を一覧表示し、クリックするとゲームと同じモデルとスキンを読み込みます。.glm を開く… と .pk3 から… で任意のモデルを開けます。左ボタンで周回、中ボタンでパン、ホイールでズーム。ターンテーブル・ボーン・ビューに合わせる はツールバーにあります。

    左の アニメーション 一覧は骨格のすべてのアニメーションと長さを表示し、名前や BOTH / TORSO / LEGS / FACE で絞り込めます。クリックで再生、ダブルクリック(または スクリプトへ)で開いているスクリプトの選択行の後ろに set ( SET_ANIM_BOTH, "…" ) を入れます。TORSO のアニメーションは SET_ANIM_UPPER、LEGS は SET_ANIM_LOWER になります。

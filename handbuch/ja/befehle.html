すべてのコマンド

イベント一覧の各コマンドの働き、すべてのカメラコマンド、すべてのマクロ、すべての SET_ フィールドと、それぞれが求める値。

コマンドは イベント 一覧から挿入し(ダブルクリック、ドラッグ、または Insert)、イベントエディタ で変更します(行をダブルクリック)。一覧のコマンドにマウスを重ねると、ゲームの開発者が書いたヘルプを読めます。組み立て方は スクリプトを書く を参照。

イベント一覧のコマンド#

各コマンドには、エディターと 3 つのビューすべての画像付きの専用ページがあります。コマンドを 1 つずつ。

コマンド働き例
flushこのエンティティでまだ待機中のコマンドをすべて消去します。FLUSH 付きの affect ブロックが最初に行うことと同じです。flush ( )
if / else比較が成り立つときだけブロックを実行します(=・<・>・! は*等しくない*)。else は if の直後に置く必要があります。if ( $get( FLOAT, "count")$, $>$, $2$ )
loopブロックを繰り返します。数値は回数で、-1 は無限です。loop ( 3 )
affectブロック内のコマンドを、名前で指定した 1 つのエンティティ(キャラクター、船、ドア)に送ります。FLUSH はエンティティの現在の動作を置き換え、INSERT は追加します。スクリプト自体はブロックを待ちません。affect ( "kyle", FLUSH )
runこのスクリプトを実行しているエンティティで、別のスクリプトを開始します。run ( "taspir_tut/kyle_spawn" )
wait指定したミリ秒だけ一時停止します。名前を指定した場合は、そのタスクが終わるまで停止します。wait ( 2000 )
waitsignal別のスクリプトが同じ名前で signal を呼ぶまで一時停止します。1 つのシグナルを待てるスクリプトは 1 つだけです。waitsignal ( "door_open" )
signalこの名前を待っているスクリプトを起こします。signal ( "door_open" )
soundエンティティのチャンネルでサウンドを再生します。台詞には CHAN_VOICE を使うと口が動きます。sound ( CHAN_VOICE, "sound/chars/kyle/..." )
moveエンティティ(ドア、足場、船)を指定したミリ秒で位置へ移動させ、指定があれば新しい角度にもします。Animate ウィンドウがこれを書いてくれます(開くドア)。move ( < 0 0 128 >, < 0 0 0 >, 2000 )
rotateエンティティを指定したミリ秒で角度(ピッチ・ヨー・ロール)へ回転させます。rotate ( < 0 90 0 >, 1000 )
useプレイヤーが押したかのように、名前でエンティティを使用します。ドアを開けたり、トリガーを発動したりします。use ( "door1" )
killこの名前のエンティティを倒します。kill ( "stormie1" )
removeこの名前のエンティティをゲームから取り除きます。remove ( "stormie1" )
print画面中央にテキストを表示します。print ( "Hello" )
remコメント。ゲーム内では何もしません。コメント化 で任意の行をコメントにできます。rem ( "camera starts here" )
declare / free変数を宣言します(FLOAT・STRING・VECTOR。1 マップにつき最大 16 個)。free で名前を解放します。declare ( FLOAT, "count" )
set値を変更します。エンティティのフィールド(SET_NAVGOAL・SET_ANIM_BOTH など。下の完全な一覧を参照)または宣言済みの変数です。set ( SET_WALKING, "true" )
cameraカットシーンのカメラを制御します。最初の値で動作を選びます。次の節を参照。camera ( ENABLE )
task名前付きのコマンドのまとまりを宣言します。まだ実行はされません。task ( "walk" )
doタスクを開始し、すぐに次へ進みます。do ( "walk" )
dowaitタスクを開始し、終わるまで待ちます。歩行なら、キャラクターが到着するまで待ちます。dowait ( "walk" )
play現在の affect ブロックのエンティティで ROFF ファイル(記録された動き)を再生します。play ( PLAY_ROFF, "taspir_tut/roffs/ravensClaw" )
ヘルプに * の印があるコマンド(例: SET_NAVGOAL)は、動作が完了して初めてタスクを終えます。だから dowait で待てるのです。

camera ( ... ):カメラコマンド#

camera の最初の値でコマンドが決まります。behaved はそのすべてをタイムラインの カメラ に表示し、ビューで再生します。時間の単位はミリ秒です。

コマンド値働き(ゲームのヘルプ)
ENABLE-ゲームをカメラモードにする
DISABLE-ゲームのカメラモードを解除する
ZOOM数値、整数通常は 80、10 でズームイン、最大は 120。2 番目の値は新しい FOV までズームする時間(ms)
MOVEベクトル、整数絶対ベクトルの原点、または TAG("targetname", ORIGIN) へ、指定したミリ秒をかけて移動
PANベクトル、ベクトル、整数現在の角度から絶対角度へ、方向 dir(dir なしなら最短方向)に、指定したミリ秒をかけてパン
ROLL数値、整数現在の角度からの相対角度オフセットへ、指定したミリ秒をかけてロール
TRACKテキスト、数値、整数トラックに乗って指定の速度で移動。最後の数値は開始位置へ補間(lerp)するかどうか
FOLLOWテキスト、数値、整数cameraGroup が一致するエンティティを angleSpeed で追う。最後の数値は開始角度へ補間(lerp)するかどうか
DISTANCE数値、整数cameraGroup(あれば)からこの距離を保つ。最後の数値は開始角度へ補間(lerp)するかどうか
FADEベクトル、数値、ベクトル、数値、整数[開始 赤 緑 青]、[不透明度] から [終了 赤 緑 青]、[不透明度] へ、[ミリ秒数] をかけてフェード(全フィールドの有効範囲は 0〜1)
SHAKE数値、整数強さ(0-16)と長さ(ミリ秒)
PATHテキストROF ファイルへのパス

マクロ#

イベント 一覧の最後にあります。マクロは複数の set コマンドを一度に挿入し、マクロを畳む で 1 行にまとめて表示します。

マクロ働きコマンド
standOnlyただ立つ。敵と警報を無視3
walkOnlyただ歩く。敵と警報を無視5
runOnlyただ走る。敵と警報を無視5
standNoAlertsただ立つ。警報を無視2
walkNoAlertsただ歩く。警報を無視4
runNoAlertsただ走る。警報を無視4
standNoEnemiesただ立つ。敵を無視2
walkNoEnemiesただ歩く。敵を無視4
runNoEnemiesただ走る。敵を無視4
standGuardNoChase敵を探して撃つが、追いかけない3
patrolRun走って巡回し、敵を追う5
patrolNoChase巡回し、敵を撃っている間も巡回ルートを守る3
patrolWalkNoChase歩いて巡回し、敵を撃っている間も歩きの巡回ルートを守る5
patrolRunNoChase走って巡回し、敵を撃っている間も走りの巡回ルートを守る5
default既定の振る舞いに戻す6

式: get、tag、random#

フィールドには固定値の代わりに式を書けます。エディターでは ヘルパー で作れます。

  • Get: get ( FLOAT, "name" ) は declare で宣言した変数を読みます。
  • Tag: tag ( "cam_door", ORIGIN ) はマップ上の ref_tag の位置(または ANGLES)を取ります。カメラはこうして目印の上に立ちます。
  • Rnd: random ( 1000, 3000 ) は 2 つの値の間の乱数です。たとえば待ち時間に使います。

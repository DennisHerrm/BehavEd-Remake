キャラクターを歩かせる

キャラクターと歩行目標を置き、スクリプトでそこへ向かわせ、マップ上で道を変えます。歩く/走る、途中の点。

手順#

  1. 1

    キャラクターを置く。 ミッション タブでビュー左端の キャラクター (NPC_spawner) タイルをクリックし、床をクリックします。インスペクターで NPC_type(... ボタンでゲームの全 NPC を検索)と 名前(例 walker)を設定します。

  2. 2

    歩行目標を置く。 移動先 (waypoint_navgoal) タイルをクリックし、キャラクターを行かせたい場所をクリックします。

  3. 3

    スクリプトで向かわせる。 エンティティ一覧でキャラクターを右クリック → affect ブロックを挿入 で affect ( "walker", FLUSH ) ブロックが入ります。一覧で歩行目標を右クリック → 移動先として挿入 (SET_NAVGOAL) で選択行の下に行が入るので、それを affect ブロックの中へドラッグします。スクリプトは affect ( "walker", FLUSH ) { set ( SET_NAVGOAL, "..." ); } になります。

  4. 4

    再生する。 再生ボタン(▶)を押すとキャラクターが歩き、通った道が黄色になります。タイムラインの行に歩行が帯で表示されます。

  5. 5

    歩く代わりに走る。 道の終点ハンドルを右クリック → 走る(この移動から)。ナビゴールの前に SET_RUNNING が書かれ、早く到着します。

  6. 6

    途中の点を作る。 タイムラインを歩行の途中に合わせ、キャラクターをつかんで横へドラッグします。その瞬間に新しいナビゴールが作られ、キャラクターはまずそこへ歩きます。

道・向き・後ろ歩きの詳細は キャラクターと道 を参照してください。

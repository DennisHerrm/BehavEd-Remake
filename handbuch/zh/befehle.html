全部命令

事件列表中每个命令的作用、所有摄像机命令、所有宏以及所有 SET_ 字段——连同它们需要的值。

命令从 事件 列表中插入(双击、拖动或按 Insert),在 事件编辑器 中修改(双击该行)。把鼠标悬停在列表中的命令上,即可阅读游戏设计者为它写的帮助文本。如何组合它们:编写脚本。

事件列表中的命令#

每个命令都有自己的页面,附有编辑器和全部三种视图的图片:逐条命令。

命令作用示例
flush清除该实体所有仍在等待的命令——这正是带 FLUSH 的 affect 块在开头所做的事。flush ( )
if / else只有比较成立时才执行该块(=、<、>、! 表示*不等于*)。else 必须紧跟在 if 之后。if ( $get( FLOAT, "count")$, $>$, $2$ )
loop重复执行其块;数字表示次数,-1 表示无限循环。loop ( 3 )
affect按名称把其块中的命令发送给一个实体——角色、飞船、门。FLUSH 替换该实体正在做的事,INSERT 则追加。脚本本身不会等待该块。affect ( "kyle", FLUSH )
run在运行本脚本的实体上启动另一个脚本。run ( "taspir_tut/kyle_spawn" )
wait暂停指定的毫秒数——或者,给出名称时,暂停到该任务完成。wait ( 2000 )
waitsignal暂停,直到另一个脚本以相同名称调用 signal。同一个信号只能有一个脚本等待。waitsignal ( "door_open" )
signal唤醒正在等待此名称的脚本。signal ( "door_open" )
sound在实体的某个声道上播放声音——对白用 CHAN_VOICE,这样嘴会动。sound ( CHAN_VOICE, "sound/chars/kyle/..." )
move在指定毫秒内把实体(门、平台、飞船)移动到某个位置——如有给出,同时转到新的角度。Animate 窗口会替你写好这些(一扇会打开的门)。move ( < 0 0 128 >, < 0 0 0 >, 2000 )
rotate在指定毫秒内把实体转到某个角度(俯仰、偏航、翻滚)。rotate ( < 0 90 0 >, 1000 )
use按名称使用一个实体,就像玩家按下了它——打开门、触发触发器。use ( "door1" )
kill杀死具有此名称的实体。kill ( "stormie1" )
remove把具有此名称的实体从游戏中移除。remove ( "stormie1" )
print在屏幕中央显示一段文本。print ( "Hello" )
rem注释——在游戏中不起作用。注释掉 可把任意一行变成注释。rem ( "camera starts here" )
declare / free声明一个变量(FLOAT、STRING、VECTOR;每张地图最多 16 个)——free 释放该名称。declare ( FLOAT, "count" )
set修改一个值:实体字段(SET_NAVGOAL、SET_ANIM_BOTH……——完整列表见下文)或已声明的变量。set ( SET_WALKING, "true" )
camera控制过场动画的摄像机;第一个值决定它做什么——见下一节。camera ( ENABLE )
task声明一组具名的命令——此时还不会运行。task ( "walk" )
do启动一个任务并立即继续。do ( "walk" )
dowait启动一个任务并等待其完成——对于行走:直到角色到达为止。dowait ( "walk" )
play在当前 affect 块的实体上播放 ROFF 文件——一段录制好的运动。play ( PLAY_ROFF, "taspir_tut/roffs/ravensClaw" )
帮助文本中标有 * 的命令(例如 SET_NAVGOAL)要等动作完成才结束其任务——正因如此,dowait 才能等待它。

camera ( ... )——摄像机命令#

camera 的第一个值决定具体命令。behaved 会在时间轴的 摄像机 下显示每一个摄像机命令,并在视图中播放。时间单位为毫秒。

命令值作用(游戏的帮助文本)
ENABLE-让游戏进入摄像机模式
DISABLE-让游戏退出摄像机模式
ZOOM数值、整数正常为 80,10 为拉近,最大为 120。第二个值是缩放到新 FOV 所用的时间(毫秒)
MOVE向量、整数在指定毫秒内移动到绝对向量原点或 TAG("targetname", ORIGIN)
PAN向量、向量、整数在指定毫秒内从当前角度沿方向 dir 平移到绝对角度(不给 dir 则走最短方向)
ROLL数值、整数在指定毫秒内按相对于当前角度的偏移翻滚
TRACK文本、数值、整数进入轨道并以指定速度移动,最后一个数字表示是否插值(lerp)到起始位置
FOLLOW文本、数值、整数以 angleSpeed 跟随 cameraGroup 匹配的实体,最后一个数字表示是否插值(lerp)到起始角度
DISTANCE数值、整数与 cameraGroup(如有)保持此距离,最后一个数字表示是否插值(lerp)到起始角度
FADE向量、数值、向量、数值、整数在 [毫秒数] 内从 [起始 红 绿 蓝]、[不透明度] 渐变到 [结束 红 绿 蓝]、[不透明度](所有字段的有效范围都是 0 到 1)
SHAKE数值、整数强度(0-16)和持续时间(毫秒)
PATH文本ROF 文件的路径

宏#

位于 事件 列表末尾。一个宏一次插入多条 set 命令;折叠宏 将其显示为一行。

宏作用命令
standOnly只是站着,忽略敌人和警报3
walkOnly只是行走,忽略敌人和警报5
runOnly只是奔跑,忽略敌人和警报5
standNoAlerts只是站着,忽略警报2
walkNoAlerts只是行走,忽略警报4
runNoAlerts只是奔跑,忽略警报4
standNoEnemies只是站着,忽略敌人2
walkNoEnemies只是行走,忽略敌人4
runNoEnemies只是奔跑,忽略敌人4
standGuardNoChase搜寻敌人,向其射击但不追击3
patrolRun跑步巡逻,追击敌人5
patrolNoChase巡逻,即使在射击敌人时也坚持巡逻路线3
patrolWalkNoChase步行巡逻,即使在射击敌人时也坚持步行巡逻路线5
patrolRunNoChase跑步巡逻,即使在射击敌人时也坚持跑步巡逻路线5
default恢复默认行为6

表达式:get、tag、random#

字段除了固定值,也可以写表达式。在编辑器中,助手 可以构建它们:

  • Get——get ( FLOAT, "name" ) 读取用 declare 声明的变量。
  • Tag——tag ( "cam_door", ORIGIN ) 取地图上某个 ref_tag 的位置(或 ANGLES)。摄像机就是这样站到标记点上的。
  • Rnd——random ( 1000, 3000 ) 是两个值之间的随机数,例如用于等待。

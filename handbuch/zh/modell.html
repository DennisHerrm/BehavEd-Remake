    模型视图与角色

    查看游戏中任意角色及其皮肤和动画,双击即可把动画写入脚本。

    在模式栏切换到 模型。NPC 列出游戏中的所有角色(来自 .npc 文件)——单击即可按游戏中的样子加载其模型和皮肤。打开 .glm… 和 从 .pk3… 可打开任意模型。鼠标左键环绕,中键平移,滚轮缩放;转台、骨骼 和 适应视图 位于工具栏中。

    左侧的 动画 列表显示骨骼的每个动画及其长度;可按名称或 BOTH / TORSO / LEGS / FACE 筛选。单击播放;双击(或 插入脚本)会在当前脚本所选行之后写入 set ( SET_ANIM_BOTH, "…" )——TORSO 动画使用 SET_ANIM_UPPER,LEGS 动画使用 SET_ANIM_LOWER。

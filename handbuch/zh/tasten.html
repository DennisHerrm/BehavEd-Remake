键盘快捷键

默认快捷键。大多数可在 编辑 → 键盘快捷键 中修改。

脚本#

Enter编辑所选命令
Insert插入在事件列表中选中的命令
Delete删除
Space复制一份
Ctrl + C复制
Ctrl + X剪切(也可 Ctrl+T)
Ctrl + V粘贴
BackspaceREM:注释/取消(Ctrl+Backspace:取消注释)
Alt + Up上移(Alt+Down:下移),保持在同一块中
Ctrl + Z撤销(Ctrl+Y 或 Ctrl+Shift+Z:重做)
Ctrl + F查找;F3 / Shift+F3 下一个/上一个
Ctrl + F2切换书签;F2 / Shift+F2 下一个/上一个
Num+展开项及其子项(Ctrl+Num+:全部)
Num-折叠项(Ctrl+Num-:全部)

文件#

Ctrl + O打开
Ctrl + S保存
Ctrl + A另存为(与原版 BehavEd 相同)
Ctrl + Shift + S全部保存
Alt + B备份;Alt+R 恢复
Alt + M最近打开的文件
Alt + P首选项;Alt+X 退出

地图与摄像机#

W A S D飞行(鼠标位于视图上);Q / E 下降/上升,Shift 加速;鼠标右键环顾四周
Ctrl + 1保存视角 1(…9);1…9 跳回
Ctrl拖动实体时:圆环以 15 度为一步;设置了网格时关闭网格,未设置时箭头吸附到 8 单位
AltAlt+拖动实体:先复制
Shift拖动飞行目标或关键帧菱形时:仅上下
Esc取消放置、路径点工具或驾驶
Enter驾驶时:在播放头处设置摄像机关键帧

时间轴#

左 / 右后退/前进 50 毫秒,鼠标位于时间轴上(Shift:1 秒)
Home / End跳到开头/结尾(鼠标位于时间轴上)
Alt拖动块时:只移动此块

窗口#

Ctrl + 滚轮界面大小(在时间轴轨道上:缩放时间轴)
